# Ithil

A fast, offline, private calendar for students on the Mac. Every event can have files attached,
and they live in real Finder folders.

> **Work in progress.** Ithil is being built in phases and isn't usable yet. A full README with
> screenshots, download and first-launch steps comes with v1.0.0.

## Build from source

Requires macOS 14 or later and Xcode 26.

```sh
git clone https://github.com/Visaug36/Ithil.git
cd Ithil
open Ithil.xcodeproj   # then ⌘R
```
